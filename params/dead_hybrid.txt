# Hybrid D detector (MT-11, 11/4): core from the CURRENT D model, start / end from the situation signs,
# then the 3-second rule.  possession/v2/dead_situation.py detect_hybrid, run by tools/dead_situations.py.
# Lines:   sign / event / back_to / confirm / end / require / must  =  日本語 | English | expression   ('#' = comment)
#   require: if it fails, the stretch is NOT this situation (the next situation is tried)
#   must   : if it fails, the stretch is NOT A STOPPAGE at all
# Ball: POSITION ONLY (ball_out, ball_out_side, ball_out_goal, ball_corner, ball_centre, ball_6yd,
#       n_approach_ball, ball_fresh, keeper_ball);
#       how the ball moves is never used. p_dead = P(dead) of the current D model (run pipeline_v2 with
#       --params {"dead_ball_motion": false} so that model does not use ball motion either).
